# مصروفي | Masroufi

تطبيق iPhone عربي لإدارة المصروف الشخصي، مبني بـ SwiftUI ويعمل دون إنترنت.

## الميزات الموجودة في النسخة 1.0

- تسجيل دخل ومصروف مع التاريخ والتصنيف وطريقة الدفع.
- دعم USD و LBP مع سعر تحويل قابل للتعديل.
- ميزانية شهرية ونسبة استهلاكها.
- رسوم بيانية للمصروف حسب التصنيف.
- بحث وفلترة وحذف العمليات.
- تصنيفات مخصصة قابلة للإضافة.
- عمليات شهرية متكررة مثل الراتب والإيجار والاشتراكات.
- أهداف توفير مع متابعة نسبة الإنجاز.
- Face ID أو رمز الجهاز لحماية التطبيق.
- حفظ البيانات محلياً في ملف JSON.
- تصدير نسخة احتياطية من البيانات.
- واجهة عربية RTL.
- GitHub Actions لبناء IPA بدون Mac.

## بناء IPA من GitHub

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح تبويب Actions.
3. افتح Build Masroufi IPA.
4. شغّل Run workflow.
5. بعد نجاح البناء نزّل Artifact باسم Masroufi-IPA.
6. فك الضغط لتحصل على Masroufi.ipa.
7. افتح IPA باستخدام SideStore لتوقيعه وتثبيته على iPhone.

## ملاحظة التوقيع

ملف GitHub Actions الناتج غير موقّع عمداً. SideStore يعيد توقيعه باستخدام Apple ID عند التثبيت.
